# 部门管理模块

第一阶段覆盖：

- 部门与部门主管
- 员工类别、汇报关系、主要 QA 负责人
- 员工固定 BU（小米 / 消费 / 新业务 / Other），作为人员、资源和负责人候选的唯一归属
- 入职日期、入职项目、离职日期和离职原因
- 第三方供应商基础管理
- “三方转正”采用与合同续约一致的档案详情入口：部门主管可安排、修改或取消待生效转正；生效日前仍按第三方员工管理，生效日当天转为汉图正式员工
- 快速视图只保留“待转正”和“正式员工”；转正完成后直接进入正式员工，原供应商、转正日期和备注保留在变更历史中，不再设置“已转正”分类
- “当前项目”来自 `qa_project_members` 的真实项目成员关系；“入职项目”只保留为入职历史信息，两者不混用
- 转岗等后续人事变化的历史表基础

权限原则：

- 部门主管是独立于 `admin / qa_lead / tester` 的组织权限。
- 系统管理员保留审计和紧急维护权限。
- 固定 BU 只能由系统管理员在员工档案中维护；未设置时显示“待归属”，不会自动并入 Other。
- QA 负责人和测试工程师不可读取供应商管理数据。
- 转正安排由部门主管或系统管理员维护，普通成员不能自行改变生效日。
- 薪资、费率和合同审批不放入本模块第一阶段；假期与审批使用独立的“假期管理”模块。
