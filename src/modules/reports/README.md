# 质量报表模块

负责质量报表页面的生命周期、样式、刷新和错误边界。

当前模块已经接管质量报表的只读数据查询、筛选状态、筛选事件、顶部指标汇总、
成员计划/实际投入分摊和周简报分组，并保留 `main.html` 中已经稳定运行的报表明细展示逻辑，通过模块上下文
`renderQualityWorkspace(results)` 与 `renderQualityResults(selection)` 调用，
确保事项完成率、TestHub 执行率、实际点数、
成员周简报、BUG 暴露和复盘口径不发生变化。

下一阶段再把报表明细展示迁入本模块；迁移时必须保持：

- BU / 项目过滤真实生效；
- QA 负责人可查看团队数据；
- 测试工程师只读取其权限范围内的数据；
- 对外质量简报不包含内部负责人姓名和内部复盘细节；
- 导出的 CSV 与页面筛选结果一致。
