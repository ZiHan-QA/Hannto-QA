# 意见反馈模块

- 模块 ID：`feedback`
- 数据表：`qa_feedback`、`qa_projects`、`profiles`
- 项目关联：可选关联 `qa_projects.id`
- 支持职责：系统管理员、QA 负责人、测试工程师
- 数据可见性：提交人只看本人反馈；系统管理员查看全部反馈
- 管理操作：仅系统管理员可更新追踪状态、回复和删除
- 外部服务：无
- 数据库迁移：`supabase/migrations/20260728_projects_and_feedback.sql`

## 验收

1. 三种职责均可提交反馈；
2. 普通用户只能看到本人反馈；
3. 系统管理员可追踪、回复和删除；
4. 删除操作需要二次确认；
5. 加载失败时显示错误和重试入口；
6. 重复进入页面不产生重复事件监听。
