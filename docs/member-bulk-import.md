# 成员批量导入

## 使用入口

系统管理员进入「系统 → 账号与权限」，点击「批量导入成员」。

1. 下载页面提供的 Excel 模板。
2. 在「成员导入」工作表填写成员，每行一人；不要修改表头。
3. 上传文件，先查看页面校验结果。
4. 所有行校验通过后点击「确认导入」。
5. 导入结果会逐行显示；失败行修正后可单独再次导入。

模板中的「填写说明」和「填写示例」工作表不会被导入。

## 数据规则

- 姓名、邮箱、初始密码、职责、是否计入资源为必填项。
- 初始密码为 8–128 位，导入后应通过安全渠道交给成员。
- 已存在的邮箱不会被覆盖。
- 一次最多导入 100 人。
- 第三方供应商成员必须选择供应商；其他类别不得填写供应商。
- 入职项目按项目全名匹配；不存在或出现同名项目时，该行不会创建。
- 创建成功后会同时写入登录账号、`profiles` 和软件质量部门档案。
- 任一成员写档失败时，服务端会删除刚创建的账号，避免半成品数据。

## 首次部署

该功能不需要新增数据库迁移，但必须部署管理员 Edge Function：

```powershell
npx --yes supabase functions deploy admin-bulk-create-users
```

Edge Function 使用 Supabase 自动提供的 `SUPABASE_URL`、`SUPABASE_ANON_KEY`
和 `SUPABASE_SERVICE_ROLE_KEY`。Service Role Key 只存在服务端，不进入网页。

## 权限

- 页面入口仅系统管理员可见。
- Edge Function 会再次校验调用者的 `profiles.role = admin`。
- QA 负责人和测试工程师即使直接调用接口也会被拒绝。
